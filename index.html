sonic cuts

Turn long videos into short vertical clips, ready to post.

sonic cuts is a self-hosted web app. It transcribes a long video or stream, picks the moments most likely to hold a viewer's attention, cuts them to 9:16, adds word-by-word captions, and can publish the finished clips to the user's own connected accounts, including TikTok.

How it works

  • The user runs the app on their own computer or server.
  • The user adds a video link or uploads a file; speech-to-text runs locally.
  • An AI model chosen by the user selects the best moments and writes titles.
  • The user reviews the clips and publishes them to their connected TikTok account.

TikTok integration

The app uses TikTok Login Kit to connect the user's own account and the Content Posting API to publish clips the user has chosen to post. It requests only the user.info.basic and video.publish permissions. The connection can be revoked at any time in TikTok settings.
