Privacy Policy

Last updated: November 20, 2026

This Privacy Policy explains how sonic cuts ("the App", "we", "us") handles information. The App is a self-hosted tool that turns long videos into short vertical clips and can publish them to the user's own TikTok account. It is developed and maintained by an individual developer based in Russia.

1. How the App works

The App runs on the user's own computer or server. Videos, clips, settings and access tokens are stored on that machine, in the user's own data folder. We do not operate a central server that receives or stores the user's videos, clips or TikTok credentials.

2. Information obtained through TikTok

If the user chooses to connect TikTok, the App uses TikTok Login Kit and the Content Posting API and requests only these permissions (scopes):

  • user.info.basic - to show the connected account's display name and avatar inside the App, so the user can see which account is connected.
  • video.publish - to publish clips that the user has chosen to post to the connected account.

The access token issued by TikTok is stored locally on the user's machine and is used only to perform the actions the user requested. The App does not read private messages, followers, or other data beyond the scopes above.

3. Information we collect

We do not collect, sell, rent or share personal information about users of the App. Data processed by the App stays on the user's own machine, except for:

  • requests the App sends directly from the user's machine to TikTok in order to log in and publish a clip, which are governed by TikTok's Privacy Policy;
  • requests the App sends to an AI provider that the user configures (for example, transcript text sent to a chosen AI service). The user chooses the provider and supplies their own key, and the provider's own privacy policy applies. If the user selects a local model, nothing leaves the machine. Speech-to-text runs locally.

4. This website

This website is a static page hosted on GitHub Pages. It has no accounts, no forms and no analytics or advertising trackers of our own. As with any web host, GitHub may process technical data such as IP addresses in server logs, as described in GitHub's privacy statement.

5. Cookies

This website does not set cookies. The locally running App may use a session cookie on the user's own machine for sign-in when accounts are enabled; this cookie is not shared with us.

6. Retention and deletion

Because data is stored on the user's own machine, the user controls retention. Clips, videos and tokens can be deleted at any time by removing the App's data folder. The user can also revoke the App's access to their TikTok account at any time in TikTok's settings (Settings and privacy, Security and permissions, Apps and websites), which invalidates the stored token.

7. Security

Access tokens and keys are stored locally and are not transmitted to us. No method of electronic storage is completely secure, so users are responsible for protecting the machine on which the App runs.

8. Children

The App is not directed to anyone under 16, and we do not knowingly collect personal information from children.

9. Changes

We may update this policy from time to time. The updated version will be posted on this page with a new "Last updated" date.
